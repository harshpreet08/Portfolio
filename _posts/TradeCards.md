# Project Overview

TradeCards is a **full-stack coupon exchange platform** that enables users to **buy, sell, and trade coupons**, engage in real-time conversations, and build trust through user reviews. It creates a secure and interactive marketplace for coupon enthusiasts.

### **Key Features:**

- **User Authentication**: Secure login and access management using Spring Security with JWT.
- **Coupon Listings**: Post, browse, and manage various coupon offers with category filters.
- **Real-Time Chat**: Built-in messaging system for seamless buyer-seller communication.
- **User Reviews**: Enables buyers to leave reviews and ratings for sellers.
- **Offline Exchange Support**: Allows users to arrange in-person coupon exchanges.
- **CI/CD Integration**: Automated builds and tests via GitLab CI pipelines.

Check out the repository on [Github](https://github.com/harshpreet08/Trade-Cards) for source code and deployment details.
